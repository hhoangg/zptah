    Debugger fallback

    What it is. Some pages ignore clicks and typing made by a script. With this on, a Mono can use Chrome's debugger on the tab it works in, which sends input those pages accept.

    When it is used. Only for sites that ignore script clicks, for example some banking and booking sites, and only on a tab a Mono is working in. Most sites never need it.

    What you will see. Chrome shows a yellow bar, "zptah Browser started debugging this browser". It stays while the Mono works on that tab and goes away when the work ends or you press Stop.

    Chrome shows a warning about debugging when it installs the extension. The extension does nothing with the debugger while this is off, and a Mono then skips those sites and tells you so.
